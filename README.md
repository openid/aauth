# Agent Auth (AAuth)

This is the working area for the specifications of the OpenID Foundation's
Agent Auth (AAuth) Working Group.

## Background

The AAuth Working Group develops specifications for agents that act on
behalf of people and organizations: how an agent proves who it is and who it
acts for, and how it obtains and uses authorization across trust domains.

Agents discover resources at runtime, act across organizational boundaries,
and need decisions from the people they act for while a task is underway.
The working group is developing a protocol for that model.

See the [charter](charter.md) for the scope, deliverables, and schedule.

## Specifications

The working group plans to develop:

- AAuth Protocol 1.0
- AAuth Supervision 1.0
- HTTP Signature Keys 1.0
- AAuth Events 1.0
- AAuth Rich Resource Requests (R3) 1.0
- AAuth Budgets 1.0

The contributed drafts are currently individual Internet-Drafts maintained
at [dickhardt/AAuth](https://github.com/dickhardt/AAuth). When the working
group adopts a draft, it moves to its own repository under the
[openid](https://github.com/openid) organization, with its own issue tracker
and Editor's Copy. This repository holds the charter, minutes, and working
group process. See [resources.md](resources.md) for links to the drafts,
implementations, and related work.

## Who do I talk to?

- Questions and proposals about an adopted specification are best raised in
  the issue tracker of that specification's repository. Use this
  repository's [issue tracker](https://github.com/openid/aauth/issues) for
  drafts not yet adopted and for the working group itself.
- Join the [mailing list](https://lists.openid.net/mailman/listinfo/openid-specs-aauth)
  to follow the working group's announcements and discussions
  (note that only people with an active IPR Contribution Agreement can post
  to the list).
- The chairs can be contacted directly at
  [openid-specs-aauth-owner@lists.openid.net](mailto:openid-specs-aauth-owner@lists.openid.net).
